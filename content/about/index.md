Hi, I'm Blagovest Petrov, and this is my personal blog. I write mostly about open source, DevOps and other random ideas. More than anything, it's a diary: a place where I document what I've built and learned, so I can find it again later.

## Bor

Most of my free time goes into [Bor](https://getbor.dev/), an open-source policy management platform for Linux desktops. It lets you define, distribute and enforce desktop configuration (browser policies, KDE and GNOME settings, polkit rules, packages) across a whole fleet of machines, in real time. Think Group Policy, but for Linux.

I've been building it at night, on weekends and on holidays since the beginning of 2025, but the idea has been growing in my head for more than 15 years. Looking after Linux computer labs has followed me since the very start of my IT career. It began at [my high school](https://tcom-sf.org/), where I was already maintaining the Linux desktops while still a student there. Later came [ESFAM](https://esfam.auf.org/), formerly IFAG, and the [Francophone Centre at Sofia University](https://www.uni-sofia.bg/index.php/bul/universitet_t/centrove/frankofonski_cent_r), whose Ubuntu workstations became the subject of [my very first blog post](/post/2013-10-04-ubuntu-12-04-desktop-with-zentyal-3-2/). In recent years I've been helping the [ZaSelata foundation](http://zaselata.org/) build Linux computer labs in village community centres, the Bulgarian читалища ([more about that](/post/2020-10-08-revival-of_the-bulgarian-villages/)).

Every one of those places needed the same thing: a way to keep many Linux desktops configured and under control without walking from machine to machine. Bor is the tool I wished I had in all of them.

## Other projects

Besides Bor, there are a few more things I build and maintain:

- [Fontmatrix](https://fontmatrix.l10n-bg.dev/): a font manager for Linux and Windows, made for designers and typesetters with large font collections. I'm the current maintainer of the project.
- [Resticara](https://github.com/VuteTech/Resticara): a Go wrapper around Restic that simplifies backups of websites, maildirs and SQL databases. It is driven by a single config file and can send notifications and generate systemd timers.
- [Dragomand](https://dragomand.l10n-bg.dev/): a per-user Linux daemon that offers offline machine translation to desktop applications over D-Bus. It runs Mozilla's Bergamot models locally and integrates with KRunner, GNOME Shell, LibreOffice and Kate.
- [Chitanka 3D](https://chitanka3d.blago.cloud/): a free educational 3D game, built with Godot, that turns the [chitanka.info](https://chitanka.info/) catalogue into a medieval stone library. You walk between the shelves and read the books.
- [l10n-bg.dev](https://l10n-bg.dev/): a site about localizing free software into Bulgarian. It collects resources, history and archived copies of old community sources.
- [Immich Frame](https://code.blago.cloud/blago/immich_frame): a tiny digital photo frame built from an old Raspberry Pi Model A+ and a 3.5" SPI display. It shows albums from a self-hosted Immich server ([more about that](/post/2026-09-17-immich-pi-photo-frame/)).
- [CRC exam trainer](https://crc-exam.blago.cloud/): a free, browser-based trainer for the Bulgarian amateur radio licence exam (Class 1 and Class 2), with mock exams, a practice mode and explanations for every question from the official CRC syllabus ([more about that](/post/2026-07-22-crc-exam-trainer/)).
- [Project Шайба](/post/2023-01-12-shaiba/): a vintage rotary phone dialer turned into a USB keyboard that types the digits you dial. It's built around an ATtiny85 board and took less than an hour to wire and code.
- [TangraPlay](https://github.com/eniac111/TangraPlay): a desktop player for the Tangra Mega Rock radio, written in Qt and QML. It plays the live stream and shows the latest news from the station's website.

## Contributions

I have also contributed to a few projects that aren't mine:

- [Maemo Leste](https://leste.maemo.org/Main_Page): a mobile Linux distribution that continues the legacy of Nokia's Maemo. I helped with the migration from Devuan 11 to Devuan 12.
- [Nextcloud](https://nextcloud.com/): the self-hosted file sync and collaboration platform. Back in 2016 and 2017 I sent pull requests for its Docker image, about Alpine Linux and PHP-FPM based variants.
- [Akregator](https://apps.kde.org/akregator/): the feed reader from KDE. I made the support for synchronization with Miniflux.
